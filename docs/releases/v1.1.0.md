# Skill Doctor v1.1.0

Skill Doctor now reviews what Agent Skill pull requests change, in addition to checking publishing quality.

## Highlights

- Git-based review of triggers, tool restrictions, instruction edits, scripts, references, and assets.
- Explainable high/medium/low risk with optional CI gating.
- Introduced/resolved findings and before/after quality scores.
- Markdown, versioned JSON, and workflow annotation outputs.
- Automatic PR base comparison in the GitHub Action, with a job summary and no write permissions.
- Dedicated standalone Skill ZIP with its runtime included.
- Hardened Action input handling and reliable release verification.

## Quick Start

```bash
python -m pip install "git+https://github.com/San-Z1/skill-doctor.git@v1.1.0"
skill-doctor diff skills --base-ref main --fail-on-risk high
```

```yaml
- uses: San-Z1/skill-doctor@v1
  with:
    path: skills
    fail-on: warning
    fail-on-risk: high
```

On PR events the Action uses the PR base SHA automatically. Otherwise, supply `compare-ref` to enable comparison. Static scan commands and existing inputs remain compatible; comparison does not gate risk unless requested.

## Downloads

- `skill_doctor-1.1.0-py3-none-any.whl`: installable Python CLI.
- `skill-doctor-skill.zip`: self-contained Agent Skill, suitable for standalone installation or Skill marketplace upload.
- GitHub source archives: the complete project, not a standalone Skill.

Python 3.10+ is required; Git is required for change review. This is a static, deterministic authoring and change-review tool, not a malware scanner or semantic safety guarantee.
